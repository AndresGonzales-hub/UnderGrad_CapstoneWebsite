# Traveling Robotics Team Website Overview

This website showcases the **Traveling Robotics Team** and the work we’ve done on our robots. It includes detailed information about the project, the robots we’ve built, and the team behind the work. The website has been built using HTML, CSS, and Bootstrap, and is hosted on **GitHub Pages**.

## Project Structure

- `index.html`: Homepage
- `project.html`: Project Overview and Description
- `robot1.html`: Robot 1 Page (includes detailed information and images)
- `robot2.html`: Robot 2 Page (similar structure to Robot 1)
- `gallery.html`: Image Gallery
- `team.html`: Team and About Us Section
- `css/`: Custom CSS files
  - `custom.css`: Main styling for the site
  - `bootstrap-4.4.1.css`: Bootstrap framework (local version)
- `js/`: JavaScript files
  - `jquery-3.4.1.min.js`: jQuery library for functionality
  - `bootstrap-4.4.1.js`: Bootstrap JS for interactive elements
- `images/`: Image files used on the site
  - `Robot1_Angle1.jpg`, `Robot2_Prototype.jpg`, etc.
- `documents/`: PDF documents related to the project
  - `Report1.pdf`, `Presentation1.pdf`, etc.

## Tools Used
- **HTML/CSS**: Handwritten and custom-coded by the team.
- **Bootstrap**: Used to create a responsive design for the site.
- **Dreamweaver**: Used for editing HTML, CSS, and managing uploads to the live server.
- **GitHub Pages**: Hosted the website with the free GitHub Pages service.
